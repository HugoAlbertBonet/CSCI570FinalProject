# CSCI570FinalProject

Repository for the final project of CSCI 570 - Analysis of Algorithms Spring 2026. 

## Structure of the repo

```
| CSCI570_Project_Minimum        # Unzip files given by the professor
|-- Datapoints                   # Examples to use while generating comparison plots
|-- SampleTestCases              # Test cases to check our algorithm
|-- Summary.docx                 # File to include insights of the results and contribution of each team member. Must be turned into pdf and included in the submission
| submission                     # Folder with the files we need to submit (except Summary.pdf as we need to generate it at the end)
|-- basic.py                     # Python file including ALL code for the memory-inefficient version
|-- basic.sh                     # Shell script to run basic.py (finished, do not touch)
|-- efficient.py                 # Python file including ALL code for the memory-efficient version
|-- efficient.sh                 # Shell script to run efficient.py (finished, do not touch)
| CSCI570_Project_Minimum.zip    # Zip files given by the professor
| CSCI570_Spring26_Project.pdf   # Instructions to develop the project
| calculations.py                # Snippet given by the professor to calculate time and memory
```
